# WellPharm: Pharmacy Management System

A comprehensive, cross-platform pharmacy management system built with Tauri and React, following Domain-Driven Design principles.

## Overview

WellPharm is a modern, efficient pharmacy management solution designed to streamline operations, enhance patient care, and ensure regulatory compliance. Built with Tauri (Rust) and React, it offers a responsive, secure, and feature-rich platform for pharmacies of all sizes.
